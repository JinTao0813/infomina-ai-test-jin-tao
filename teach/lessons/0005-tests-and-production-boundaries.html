Tests as executable contracts

Hand-calculated entropy cases independently check the mathematics. API tests assert that explicit choices shift applied discovery by the documented amount, sparse profiles suppress inferred weekend effects, and ranking sorts exact scores before rounded display values and candidate-ID tie breaks. Safety tests inspect response keys; frontend tests verify that a user action sends the expected request and visibly reranks results.

Reproducibility and artifact freshness

  • uv.lock + uv sync --frozen lock Python resolution; package-lock.json + npm ci do the same for the frontend.
  • The executed notebook is authoritative; the exporter never executes it or reads raw check-ins.
  • The generated analysis JSON records the notebook SHA-256. npm run build first runs a freshness check.
  • Generated chart assets are fingerprinted and re-exported in isolation during validation.
  • The candidate catalog has a deterministic --check path against identical local source files.
  • The notebook bootstrap uses fixed seed 20250308.

What is not production

Still absent: continuous integration, deployment, authentication, persistence, current venue data, upstream ownership contracts, orchestration, telemetry, SLOs, incremental feature computation, calibrated confidence, learned relevance, privacy review, retention enforcement, power analysis, and online experimentation.

The local API and frontend are real software, but “full-stack prototype” is not synonymous with “production recommender.” FastAPI loads committed fixtures in memory. The ranker is hand-designed and deterministic. It demonstrates behavior and testability, not utility.

“I would call the metric and artifact pipeline production-oriented foundations and Discovery Mode a tested local prototype. The tests establish mathematical, contract, safety, and UI behavior. They do not establish recommendation quality, current venue validity, operational readiness, or privacy approval.”

Retrieve

What does the exporter freshness test protect?
It binds the static website artifact and extracted assets to the exact executed notebook bytes, so the site cannot silently present stale notebook content.
Why don't 42 passing cases validate the product?
They test deterministic implementation behavior, not whether real users benefit. Recommendation usefulness requires current consented data and a randomized outcome experiment.
