Build entropy from counts, probabilities, and surprise.

By the end, you should be able to calculate the metric by hand and explain raw and normalized values.

counts → bits

This topic was new to me when I started the assignment. StatQuest's introduction to entropy helped me understand surprise first, and I used the assignment formula and hand calculations to connect that idea to venue visits.

For one user, count events at each venue. Divide each venue count by the user's total events to estimate pᵢ. A rare event carries more information, −log₂pᵢ; entropy is the probability-weighted average surprise.

pᵢ = nᵢ / N   ·   H = −Σ pᵢ log₂(pᵢ)

Hand example: counts [3, 1]

Probabilities are 0.75 and 0.25. Therefore:

H = −(0.75 log₂0.75 + 0.25 log₂0.25) ≈ 0.811 bits

A balanced [2, 2] distribution has 1 bit; a concentrated [4, 0] distribution has 0 bits. Same event count, different evenness.

Raw versus normalized

With K observed locations, maximum entropy occurs under a uniform distribution and equals log₂K. The solution reports:

Hₙₒᵣₘ = H / log₂(K),   defined as 0 when K ≤ 1
  • Raw entropy: absolute diversity in bits; reflects variety and evenness.
  • Normalized entropy: evenness relative to this user's observed repertoire; intended range [0, 1].
  • Counts: observation count and unique-location count remain necessary context.

Interpretation boundary

Entropy summarizes the recorded distribution. It does not measure distance, travel radius, sequence, dwell time, spending, all mobility, or a personality trait. Two users can have equal entropy with completely different categories or geography.

Base choice

The implementation intentionally fixes base 2, so raw entropy is always reported in bits. A different valid base would only rescale raw entropy; normalized entropy is base-invariant when numerator and denominator share the base. Keeping the API fixed avoids ambiguous units. The actual public contract has only three inputs: data, group columns, and location column.

Retrieve

What maximizes entropy for fixed K?
A uniform event distribution across all K locations; each probability equals 1/K and H equals log₂K.
Why report counts alongside normalized entropy?
Normalization adjusts the theoretical ceiling but does not remove sampling variability, self-reporting bias, or dependence on the observed repertoire.
