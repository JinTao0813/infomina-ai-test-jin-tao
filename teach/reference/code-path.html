Code path

Follow raw check-ins into analysis, safe static presentation, and the live deterministic prototype.

Analysis path

1Raw bytesdataset_tsmc2014/*.txt — local ignored Latin-1, headerless, eight-column TSV.
2load_checkinsValidate city/field counts; parse explicit dtypes; reject blanks, coordinates, timestamps; derive UTC and city-local time.
3summarize_checkinsAggregate quality facts, duplicates, activity, offsets, homes, and venue metadata conflicts.
4prepare_city_dataReturn exact-deduplicated rows plus immutable quality report.
5Notebook contextDerive weekday/weekend per city before concatenating timezone-specific frames.
6calculate_location_entropyValidate three-argument API → group-location counts → probabilities → base-2 entropy → normalization.
7Notebook evidenceVenue/category, activity relation, paired temporal, cohorts, bootstrap, and home sensitivity.
8Product argumentEvidence → interpretation → opportunity comparison → hypothesis → evaluation/guardrails.

Static website path

1Executed notebookSingle analytical source of truth; export does not execute it.
2export_notebookReject unsafe content; structure Markdown/tables; extract accessible fingerprinted assets.
3analysis.jsonCommitted artifact with source label, generation time, notebook SHA-256, sections, code, and outputs.
4Next.js /Server-render the generated case study; no raw files or FastAPI required.
5Prebuild checkRe-export in isolation and fail when notebook, artifact, or assets differ.

Discovery Mode path

1Offline profile builderWrite four fixed synthetic histories; never read source users.
2Offline catalog builderFilter and aggregate source venues → sixteen rounded, supported, pseudonymous candidates.
3FastAPI startupPydantic validates safe fixtures; no per-request raw-data access.
4Browser controlsProfile + context + explicit mode POST to /recommendations.
5Python rankerApplied discovery → candidate novelty → curved score → exact ordering → reasons.
6React resultsRender provenance, reasons, score disclosures, live updates, fallback/error/empty states.
