Prototype defense

Exact equations, terms, boundaries, and answers for Discovery Mode.

One-sentence claim

Discovery Mode is a deterministic, inspectable implementation of a product hypothesis over synthetic profiles and privacy-safe historical candidates—not a trained or validated recommender or current place guide.

Applied discovery

I=.60V+.40C
Q=confidence·I+(1−confidence)·.50
W=confidence·weekend_delta (reliable weekend only)
A=clamp(.70E+.30Q+W, 0, 1)

E: familiar .20, balanced .50, something new .80. If confidence < .50: Q=.50, W=0. Routine + weekend + balanced gives A=.58028.

Candidate score

D=1−category_familiarity
N=.65·aggregate_novelty+.35·D
α=A1.5
final=(1−α)·baseline_relevance+α·N

Baseline relevance = .35 + .60 × aggregate popularity. Aggregate novelty = 1 − aggregate popularity. Sort exact final descending, generated ID ascending; round response values afterward.

Data facts

  • 4 profiles: fixed and synthetic; builder reads no source users.
  • 16 candidates: 8 per city, data-derived aggregate historical records.
  • Eligibility: ≥30 check-ins and ≥15 distinct visitors after sensitive-category exclusion.
  • Minimization: rounded support; no source user/venue IDs, coordinates, timestamps, trajectories, or names.
  • “New”: absent from example category history or less common in 2012–2013 sample.

Architecture facts

  • / renders committed notebook-derived JSON/assets; no API/raw data needed.
  • /prototype/discovery calls local FastAPI directly.
  • FastAPI loads safe fixtures in memory and owns ranking logic.
  • Exporter reads—but never executes—the notebook; source hash and isolated re-export enforce freshness.
  • Catalog generation alone reads raw check-ins; runtime services do not.

Fast defenses

ChallengeAnswer
“Why these weights?”Illustrative, transparent choices to demonstrate behavior; only outcome data could calibrate them.
“Is popularity relevance?”No. It is an explicitly illustrative baseline transform.
“Are candidates synthetic?”No. Profiles are synthetic; candidates are filtered pseudonymous aggregates from historical venue records.
“Is this anonymous?”Minimized and aggregated, but thresholds are not a formal privacy proof.
“What did tests prove?”Math, contracts, determinism, safety fields, artifact freshness, and UI behavior—not usefulness.
“What validates it?”A powered user-level randomized experiment on current consented data with guardrails.
